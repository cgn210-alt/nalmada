# 날마다 · 퐁당 (nalmada)

CGN 퐁당 "날마다" 콘텐츠를 매일 유저에게 배포하기 위한 웹앱입니다.
관리자가 일주일치 콘텐츠(유튜브/OTT 링크)를 미리 만들어 두면, 매일 자동으로 그날 콘텐츠가 표시됩니다.

- 배포 주소: https://cgn210-alt.github.io/nalmada/
- 호스팅: GitHub Pages (main 브랜치 / 루트)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (유저 화면 + 관리자) |
| `content.json` | 날짜별 콘텐츠 데이터 (여기만 바꿔서 올리면 됨) |
| `fondant-logo.png` | 상단 로고 |
| `사이트-올리기.bat` | git add/commit/push 자동 실행 |

## 매주 운영 방법

1. `index.html`을 브라우저로 열고 우측 상단 ⚙︎(관리자) 클릭
2. 편집 탭에서 요일 칩(오늘~+6일)을 눌러가며 각 날짜의 콘텐츠 링크를 채움
3. 배포 탭 → `content.json 내려받기` → 이 폴더의 `content.json`을 교체
4. `사이트-올리기.bat` 실행 → 1~2분 후 사이트에 반영

콘텐츠는 날짜별로 저장되며, 그날 콘텐츠가 없으면 가장 최근 날짜 것으로 자동 대체됩니다(빈 화면 없음).
유튜브 링크는 썸네일과 출처가 자동으로 표시됩니다.
